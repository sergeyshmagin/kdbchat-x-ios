# Изменения UI главного экрана (HomeScreen)

## Дата изменений
04.08.2025

## Внесенные изменения

### 1. Убрана иконка профиля сверху
- **До**: В левом верхнем углу отображалась иконка профиля пользователя с возможностью перехода в настройки
- **После**: Иконка профиля заменена на иконку видеокамеры для будущего функционала создания конференций
- **Файл**: `ElementX/Sources/Screens/HomeScreen/View/HomeScreen.swift`
- **Строки**: 206-214

### 2. Прямое открытие настроек по нажатию на таб
- **До**: Нажатие на таб "Настройки" показывало промежуточный экран с кнопкой "Открыть настройки"
- **После**: Нажатие на таб "Настройки" сразу открывает модальное окно настроек
- **Файл**: `ElementX/Sources/Screens/HomeScreen/View/HomeScreen.swift`
- **Строки**: 159-166

### 3. Изменен цвет индикатора уведомлений
- **До**: Красная точка на иконке профиля
- **После**: Зеленая точка на табе настроек
- **Файл**: `ElementX/Sources/Screens/HomeScreen/View/HomeScreen.swift`
- **Строки**: 164-169

### 4. Улучшена логика отображения индикатора
- **До**: Индикатор показывался всегда на табе настроек
- **После**: Индикатор показывается только когда есть требующие внимания пункты (`requiresExtraAccountSetup == true`)
- **Условие**: `tab == .settings, context.viewState.requiresExtraAccountSetup`

### 5. Удален промежуточный экран настроек
- **До**: Таб настроек показывал промежуточный контент с кнопкой
- **После**: Промежуточный контент удален, так как настройки открываются напрямую
- **Файл**: `ElementX/Sources/Screens/HomeScreen/View/HomeScreen.swift`
- **Удаленные строки**: settingsContentView method
